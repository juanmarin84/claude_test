# Dragón Papercraft 3D

Visor web interactivo hecho con Three.js de un dragón low-poly (escamas verdes).

- Gira solo; arrastra para orbitar, rueda o pellizco para zoom.
- Botones: giro automático, piel de papel naranja, ver facetas y restablecer vista.

Archivos: `index.html` (página), `dragon-model.js` (modelo GLB embebido), `dragon.glb` (modelo original).
